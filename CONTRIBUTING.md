# Sobre este repositorio

`neuralab-agent-showcase` es un **showcase técnico de arquitectura**, no un producto
con desarrollo comunitario abierto. Su objetivo es documentar cómo Neuralab diseña y
construye agentes conversacionales IA multi-tenant con RAG y hardening.

## Contribuciones

No buscamos pull requests de features. Sí son bienvenidos:

- **Issues** que señalen errores en la documentación, en los diagramas o en los
  ejemplos de código.
- **Preguntas** de arquitectura: si algo del diseño no queda claro, abrí un issue y
  lo explicamos.

## Regla no negociable

Ningún archivo de este repo puede contener credenciales, tokens, connection strings,
datos personales, nombres de clientes reales ni identificadores de producción. Todo
ejemplo es genérico y ficticio. Cualquier aporte debe respetar esto.
